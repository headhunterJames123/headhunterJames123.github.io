# James Zhang 个人主页

适用于 GitHub Pages 的静态个人网站。不需要安装软件、运行构建或购买服务器。

## 发布

1. 在 GitHub 账号 `headhunterJames123` 下创建公开仓库，名称为 `headhunterJames123.github.io`。
2. 将 `index.html`、`style.css`、`content.js`、`app.js` 上传至仓库根目录。不要只上传外层文件夹或 ZIP。
3. 打开仓库 Settings → Pages，选择 Deploy from a branch，分支 main，目录 / (root)，保存。
4. 等待部署完成，访问 `https://headhunterjames123.github.io`。

## 更新介绍和职位方向

在 GitHub 打开 `content.js`，点击编辑按钮，修改文字后保存。网站会随部署更新。

- `name`：展示姓名。
- `headline`：首页的一句话介绍。
- `bio`：个人介绍，每个引号内是一段。
- `email`、`wechat`、`linkedin`、`github`：愿意公开的联系方式。留空不显示。LinkedIn 和 GitHub 填写完整的 https 地址。
- `directions`：招聘方向。复制其中一组可新增方向，修改 `title`、`description`、`roles` 即可更新内容。

编辑时保留引号、逗号和括号。英文单引号需要写成 `\'`，或改用中文引号。
